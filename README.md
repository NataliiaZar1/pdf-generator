# PDF Generator

Учебная программа на Python. Она берёт данные счёта из файла CSV или JSON, подставляет их в HTML-шаблон и сохраняет готовый PDF. После этого программа пытается открыть PDF на компьютере.

Русский текст в PDF выводится шрифтом DejaVu Sans. Файлы шрифта уже лежат в папке `fonts`, отдельно устанавливать шрифт не нужно.

## Структура папок

```
PDF_generator/
├── main.py                  — программа
├── requirements.txt         — список библиотек Python
├── README.md                — эта инструкция
├── data/
│   ├── invoices.csv         — учебные счета в виде таблицы
│   └── invoices.json        — те же счета в формате JSON
├── templates/
│   ├── invoice.html         — классический вид счёта
│   └── invoice_modern.html  — современный вид счёта
├── fonts/
│   ├── DejaVuSans.ttf
│   └── DejaVuSans-Bold.ttf
└── output/                  — сюда сохраняются готовые PDF
```

В CSV один товар занимает одну строку. Строки с одинаковым номером счёта программа собирает в один счёт. В JSON у каждого счёта сразу есть список товаров `items`.

## Что уже есть на компьютере

Проверен Python 3.12. Этого достаточно: программе нужен Python 3.10 или новее.

Библиотеки из `requirements.txt` пока не установлены. На Windows WeasyPrint не заработает от одной команды `pip install`: ей нужна системная библиотека Pango. Её на компьютере сейчас нет, поэтому установка остановлена до вашего решения.

## Установка WeasyPrint на Windows

Сделайте эти шаги по порядку.

1. Скачайте установщик MSYS2 с сайта [https://www.msys2.org/](https://www.msys2.org/).
2. Установите MSYS2 с обычными настройками. Он появится в папке `C:\msys64`.
3. В меню Пуск откройте программу **MSYS2 UCRT64**. Это отдельное чёрное окно, не обычная командная строка Windows.
4. В этом окне выполните команду и согласитесь на установку, если программа спросит:

```
pacman -S mingw-w64-ucrt-x86_64-pango
```

5. Закройте окно MSYS2.
6. Откройте новое окно PowerShell, перейдите в папку проекта и создайте виртуальное окружение. Это отдельная папка `.venv` с библиотеками только для этого проекта:

```
cd "C:\Users\natza\OneDrive\Documents\ИИ\PDF_generator"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

7. Проверьте, что WeasyPrint видит системные библиотеки:

```
python -m weasyprint --info
```

Если команда пишет, что не может загрузить библиотеку, в том же окне PowerShell выполните:

```
$env:WEASYPRINT_DLL_DIRECTORIES = "C:\msys64\ucrt64\bin"
python -m weasyprint --info
```

Эта настройка действует, пока открыто текущее окно. Перед запуском программы её нужно выполнить снова, если проверка без неё не прошла.

## Если PowerShell не даёт включить окружение

Иногда Windows пишет, что выполнение сценариев отключено. Тогда один раз выполните:

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

После этого снова выполните `.\.venv\Scripts\Activate.ps1`.

В обычной командной строке `cmd` окружение включается другой командой:

```
.venv\Scripts\activate.bat
```

Когда окружение включено, в начале строки появляется `(.venv)`.

## Запуск программы

В том же окне, где включено окружение, выполните:

```
python main.py
```

## Как работает меню

Программа показывает списки и просит ввести номер пункта.

```
========================================
           PDF GENERATOR
========================================

Доступные файлы данных:

1. invoices.csv
2. invoices.json

Выберите файл данных:
```

Дальше она показывает шаблоны:

```
Доступные шаблоны:

1. invoice.html
2. invoice_modern.html

Выберите шаблон:
```

Потом показывает счета:

```
Доступные счета:

1. INV-001
2. INV-002
3. INV-003

Выберите invoice ID:
```

Нужно вводить номер: `1`, `2` или `3`. Можно также ввести сам номер счёта, например `INV-001`. Если ввести что-то другое, программа объяснит ошибку и попросит выбрать снова.

Готовый файл появляется в папке `output`. Имя берётся из номера счёта, например `INV-001.pdf`. Если такой PDF уже есть, программа не затирает его и сохраняет новый как `INV-001_2.pdf`. Затем она открывает файл программой, которая на компьютере назначена для PDF.

## Где что лежит

- Исходные данные: папка `data`.
- Шаблоны оформления: папка `templates`.
- Готовые PDF: папка `output`.
- Шрифт для русского текста: папка `fonts`.

Программу можно перенести в другую папку на компьютере. Она ищет данные рядом с файлом `main.py`.

## Возможные ошибки и что делать

- **Папка data не найдена.** Создайте папку `data` рядом с `main.py` и положите туда CSV или JSON.
- **В папке data нет файлов CSV или JSON.** Проверьте имена и расширения файлов.
- **Папка templates не найдена или в ней нет HTML.** Рядом с `main.py` должна быть папка `templates` с файлами `.html`.
- **Неверный номер меню.** Введите номер, который есть на экране, без точки и лишних слов.
- **Файл повреждён.** CSV должен содержать нужные столбцы. JSON должен быть правильным списком счетов. Программа напишет, в каком месте ошибка.
- **Отсутствует invoice_id.** У каждого счёта должен быть номер.
- **Счёт не найден.** Такого номера нет в выбранном файле. Выберите номер из показанного списка.
- **Не удалось создать PDF.** Чаще всего не установлены Pango или библиотеки Python. Вернитесь к разделу про установку WeasyPrint и выполните `python -m weasyprint --info`.
- **Не удалось открыть PDF.** Сам файл при этом уже сохранён. Программа покажет полный путь, откройте его двойным щелчком.
- **Папки output не было.** Программа создаст её сама. Если вместо папки случайно лежит файл с именем `output`, переименуйте этот файл.
- **Вместо русских букв квадраты.** Шрифты должны оставаться в папке `fonts`. Не переименовывайте `DejaVuSans.ttf` и `DejaVuSans-Bold.ttf`.
- **Антивирус ругается на WeasyPrint.** У этой библиотеки бывают ложные срабатывания. Проверьте предупреждение и при необходимости сообщите о нём в антивирус.

## Другие системы

На macOS программа открывает PDF командой `open`. На Linux — командой `xdg-open`. Установка WeasyPrint на этих системах отличается от Windows; для этого задания достаточно инструкции для Windows выше.
